# 方向2：PIT 基本面因子 × 中证500 — 财报质量/成长/现金流/估值的多因子检验

> **核心结论（2026-08-14，全链数据到位后收敛）**：**方向2 全否定**。
> 20 个基本面因子（16 财报 + 4 估值）在中证500 的月末截面预测力，经三层检验层层剥落后无 alpha：
> **线性提纯 0/20 通过 → ML 合成 OOF SR +0.52 看似有 → 严格前向固定池 WF 崩塌为 SR −0.125 → PIT-Select 每年重选池选不出池（2015–2025 全空）**。
> 这与价量链路（OOF 1.906 → WF 0.25）完全同构的 selection bias 模式：全样本选池制造的「上限」在去 bias 后归零甚至翻负。
> **价值在于：基本面是量价之外唯一未测的信息源，现在检验完整、证据闭合。**

> **数据源变更记录（2026-08-14）**：baostock 按 IP 累计配额封禁（~5 万次/天），74 万次查询需跨天 20 天。
> 换源组合：**16 财报因子 = akshare 新浪财务指标（1625 只 × 1 调用 ≈ 90min，无配额墙）+ 4 估值因子 = baostock 日线（1630 次查询单次拉完）**。
> PIT 对齐从「公告日 pubDate+1」退化为「法定截止日+1」（akshare 新浪无公告日）——保守偏误，非未来函数，**可能部分解释了 FM 弱**。

## 假设检验

$$H_0:\ \text{PIT 基本面因子在中证500 的月度预测力} \le 0\ \text{（扣成本后无可交易 alpha）}$$
$$H_1:\ \text{质量/成长/现金流/估值在中小盘定价低效下具有显著截面预测力}$$

| 检验维度 | 方法 | 控制的风险 |
|----------|------|------------|
| 因子提纯 | 月末截面四维 AND（\|IC_IR\|>0.15, \|IC_t\|>2.0, \|FM_t\|>2.0, CS_eff>0.5），Bonferroni 从严 \|t\|>3.09 | 季频因子日频采样的 IC 自相关虚高 |
| 冗余剔除 | Rank IC \|corr\|>0.8 贪心剔除（池 ≤10） | 财报因子强共线虚增维度 |
| 非线性合成 | LightGBM + PurgedTimeSeriesSplit（purge 2 月末单位） | 时序泄露、月度标签自相关 |
| 样本外 | **固定池 WF**（全样本选定池，逐年重训严格前向） | 全样本选池的 selection bias（上限对照） |
| 终极去 bias | **PIT-Select WF**（每年重选池 + 重训，2015-2025） | 任何「选池后再回测」的幸存者偏差 |
| 显著性 | Block bootstrap（block=20, n=10000）夏普 p 值 | 收益偶然性 |
| 幸存者偏差 | PIT 中证500 月末快照并集（1625 只含退市股） | 回看当前成分、财报未来函数 |

| 项 | 值 |

| 时间范围 | 2010-01-01 ~ 2025-12-31（月末截面 **192** 个独立观测） |
| 因子库 | **20** = 16 财报（akshare 新浪）+ 4 估值（baostock 日线） |

| 样本量 | 月末长表 **95,996 行**（192 月末 × ~500 成员，12 特征 + 2 市场） |
| 调仓频率 | 月度（月末信号 → 次日生效 → 持有至下月末） |
| 成本 | 双边 0.3%（与全链路一致） |

## 1. 方法论：月末截面采样（与价量链路分道）

**为什么必须月末采样**：财报因子是季频数据，前向填充到日频后相邻交易日因子值完全相同。
逐日 IC 强自相关 → t 值被 √(过采样) 放大。**实证（2026-08-14 全量数据再确认）**：

| 口径 | IC_t 中位比 |
|------|-----------|
| 日频 / 月末 | **5.6×**（20 因子中位） |

同一弱信号，日频采样会虚高到「显著」，月末口径则如实显现其弱——这是方向2 与价量链路最本质的方法论差异，也是为什么本报告所有判决都以月末口径为准。

## 2. 因子清单（20 = 16 财报 + 4 估值）

| 类别 | 因子 | 方向(先验) | 数据源 |
|------|------|-----------|--------|
| 质量 | roeAvg, npMargin, gpMargin, epsTTM | + | akshare 新浪 |
| 成长 | YOYNI, YOYAsset | + / − | akshare 新浪 |
| 现金流 | CFOToNP, CFOToOR, ebitToInterest | + | akshare 新浪 |
| 营运 | NRTurnRatio, INVTurnRatio, CATurnRatio, AssetTurnRatio | + | akshare 新浪 |
| 杠杆 | liabilityToAsset, currentRatio, cashRatio | − / + | akshare 新浪 |
| 估值 | peTTM, pbMRQ, psTTM, pcfNcfTTM | − | baostock 日线 |

> 缺失 5 因子：dupontROE（≈roeAvg 可近似）、YOYPNI、YOYEPSBasic、CFOToGr、CAToAsset —— 新浪财务指标无对应列，方向2 检验以实际可用的 20 因子为准。

## 3. 因子提纯（月末四维 AND）—— **0/20 通过，方向一致 20/20**

![因子提纯（月末 IC_IR vs 日频对照 + t 值）](figures/01_purify_monthly.png)

**提纯结果（全量数据）**：

| 观察 | 值 |
|------|-----|
| 四维通过 | **0/20**（无因子同时过 IC+FM+CS） |
| IC_t 显著（\|t\|>2） | **5 个**：pbMRQ(−2.71) peTTM(−2.62) psTTM(−2.33) CFOToOR(+2.25) CFOToNP(+2.16) |
| FM_t 显著（\|t\|>2） | **0 个**（最高 CFOToOR +1.31） |
| 方向一致性 | **20/20**（估值负向、质量/成长/现金流正向全对） |
| 日频/月末 IC_t 比 | **5.6×**（IC 自相关通胀实证再确认） |

**核心矛盾解读**：rank IC 显著（5 因子 \|IC_t\|>2）但 Fama-MacBeth 线性回归全灭（最高 t=1.31）——
信号在**单调非线性层面**存在（top/bottom 分位有区分）、**线性层面不显著**。这指向两类可能：
(a) 信号真实但非线性，LightGBM 可能抓取；(b) 弱信号 + 小样本（192 截面），rank 层面的显著性本身是噪声。
**提纯本身给出的判决：无因子过四维 → 若严格四维标准，方向2 到此即否定。**
为完成检验（铁律 4：等权基线 → ML 合成 → 去 bias），退化 IC_t top-10 诊断池继续跑，但**明确标注：该池含 selection bias，仅作上限**。

## 4. LightGBM 合成（退化诊断池，含 selection bias 上限）

- 池：IC_t 绝对值 top-10（pbMRQ/peTTM/psTTM/CFOToOR/CFOToNP/epsTTM/CATurnRatio/YOYNI/AssetTurnRatio/gpMargin）
- CV：`PurgedTimeSeriesSplit(n_splits=5, purge_days=2)`（月末单位）
- 样本：38,253 有效标签

| 指标 | 值 |
|------|-----|
| CV AUC | 0.531 ± 0.009 |
| OOF 月末 Rank IC | **+0.058**（t=+4.63, n=159） |
| OOF LO 回测 | **SR +0.524** 年化 +12.2% mdd −54%，bootstrap p=0.027 |
| LO + MA200 gate | SR +0.399 年化 +6.2%（gate 压收益，无增益） |
| 成员等权基准 | SR +0.357 年化 +9.4% |

**⚠️ 此处「看似有 alpha」是 selection bias 的产物**：退化池从全样本 192 截面提纯结果选出，
预测集与选池数据重叠。真实 alpha 必须看下一节的严格前向检验。

## 6. Walk-Forward —— 方向2 的核心判决

### 6.1 固定池 WF（pool 全样本选定，逐年重训，严格前向）

| 年 | 池大小 | 年化 | SR |
|----|-------|------|-----|
| 2015 | 10 | +1.14% | +0.17 |
| 2016 | 10 | −1.69% | −0.34 |
| 2017 | 10 | −2.02% | −0.33 |
| 2018 | 10 | −2.47% | −0.39 |
| 2019 | 10 | −1.40% | −0.19 |
| 2020 | 10 | +0.30% | +0.04 |
| 2021 | 10 | −0.36% | −0.07 |
| 2022 | 10 | −0.17% | −0.04 |
| 2023 | 10 | +1.54% | +0.34 |
| 2024 | 10 | −1.93% | −0.52 |
| 2025 | 10 | −0.69% | −0.21 |
| **合并** | | **−0.71%** | **−0.125** |

**OOF SR +0.52 → 固定池 WF SR −0.125**：selection bias 把「上限 alpha」完全吃掉并翻负。
这与价量链路（1.906 → 0.25）同构——**全样本选池的 OOF 高估是系统性陷阱**。

### 6.2 PIT-Select WF（每年重选池，终极去 bias）

**2015–2025 逐年用截至当年的数据做四维提纯，每年重选池结果全部为空**：

| 年 | 重选池 |
|----|-------|
| 2015–2025 | 全部 `[]` |

**含义**：四维 0 通过不是全样本偶然——**任何子样本（截至任何年份）都选不出基本面因子池**。
这是比「固定池 WF SR 为负」更强的全否定证据：不仅去 bias 后无 alpha，连「每年是否有信号」都稳健地答否。

## 7. 中性化与容量诊断

- 行业中性化：未单独跑（行业快照非 PIT，且信号本身已弱到无需中性化即可判定否定）
- 容量：月调仓 LO 名义容量充足，但 SR −0.125 下容量无意义
- **局限披露**：
  1. **PIT 退化**：akshare 新浪无公告日，用法定截止日+1 → 损失提前披露公司的 PEAD alpha。
     FM 弱（最高 t=1.31）**可能部分由此导致**——换公告日源（tushare 积分档）后信号或更强，但当前数据下证据闭合。
  2. **5 因子缺失**：新浪无 dupontROE/YOYPNI/YOYEPSBasic/CFOToGr/CAToAsset。
  3. **退市股财报覆盖**：akshare 对退市股可能缺失（退市前 1-2 年）→ 选择性缺失偏乐观。
  4. **财报重述风险**：新浪值可能为修订后版本。

## 最终判决

```
┌────────────────────────────────┬──────────┬───────────────────────────────────┐
│ 检验维度                        │ 结果     │ 判决                              │
├────────────────────────────────┼──────────┼───────────────────────────────────┤
│ H1 质量/成长/现金流 IC          │ 0/20 四维 │ 拒绝（方向全对但强度不足）          │
│ H2 估值负向预测                │ IC_t 显著 │ 弱支持→拒绝（FM 全灭, WF 翻负）     │
│ H3 ML 月调仓 > 等权基线         │ OOF+0.52 │ 拒绝（固定池 WF −0.125 证伪）       │
│ H4 去 bias 后信号保留           │ 每年空池 │ 拒绝（PIT-Select 2015-2025 全空）    │
│ H5 edge 逐年稳定性              │ 11 年仅 4 年正 | 拒绝                        │
│ WF 固定池 vs PIT-Select         │ −0.125 vs 空 | selection bias = 全部 alpha    │
└────────────────────────────────┴──────────┴───────────────────────────────────┘
```

**方向2 判决：PIT 基本面因子（质量/成长/现金流/估值）在中证500 的月度截面预测力——全否定。**
线性提纯 0/20 通过；ML 合成的「OOF 优势」是 selection bias 全量产物（−0.125 证伪）；
PIT-Select 每年重选池稳健选不出；估值价值信号（IC_t 显著）在去 bias 后不构成可交易 edge。

**弧线状态：方向2 是量价之外唯一未测信息源，现检验完整。量价（三方向）+ 基本面（方向2）全部收敛否定。**
研究弧线完整闭合。
