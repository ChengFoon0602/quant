# 收益/成本口径统一论证

> 状态：**待决策**（未改代码）
> 涉及：`models/portfolio_backtest.py::build_portfolio`、`build_portfolio_naive`
> 影响：几乎所有截面 / ML 策略报告的历史结论

---

## 1. 问题陈述

全仓库存在**两套收益定义**并存：

| 模块 | 收益定义 | 记在哪一天 | 成本口径 |
|------|---------|-----------|---------|
| `backtest/engine.py` | `close.pct_change()` | t→t+1 记在 t+1 | 买/卖分离 0.026%/0.076% |
| `backtest/cross_section.py` | `close.pct_change()` | t→t+1 记在 t+1 | 买/卖分离 |
| `models/labels.py` | `close(t+6)/close(t+1)-1` | 持仓期（跨 5 日） | — |
| **`models/portfolio_backtest.py`** | **`close.shift(-2)/close.shift(-1)-1`** | **t+1→t+2 记在 t** | **cost/2 对半** |
| `risk/portfolio.py` | `close.pct_change()`（本次已改） | t→t+1 记在 t+1 | 买/卖分离（本次已改） |

核心分歧在于 `models/portfolio_backtest.py` 的错位收益。

---

## 2. 错位收益的精确数学含义

已用数值实验验证（2026-09）：

```
r_wrong[t] = close.shift(-2)/close.shift(-1) - 1
           = close(t+2) / close(t+1) - 1      # 记在 t 日
```

即：**t 日的收益字段里装的是 t+1→t+2 的收益**。

配 `W_lag = W_held.shift(1)` 后：

```
port_ret[t] = W_held[t-1] · r_wrong[t]
            = W_held[t-1] · (t+1→t+2 的收益)
```

而 `W_held[t-1]` 由 `W_target.rolling(hold_days).mean()` 得到，`W_target[t-1]` 用的是 **t-1 日的信号**。

因此时序是：**t-1 日的持仓，吃到了 t+1→t+2 日的收益**。

---

## 3. 两种可能的定性

### 定性 A：真实未来函数

- t 日、t+1 日的信号都还没生成，收益已经被计入 `port_ret[t]` 之前的序列里。
- 若严格按「信号 t 收盘 → t+1 开盘买 → 持有 → 卖出」的语义，`W_held[t-1]` 不可能在 t+1→t+2 就兑现收益。
- 结论：这是**未来函数**，会导致截面/ML 组合的夏普虚高。

### 定性 B：有意的「单日持有」近似（作者意图）

- docstring 明确写「无未来函数的日收益：close(t+2)/close(t+1)-1」，作者**意图**是模拟「信号日 t 收盘 → t+1 开盘买入 → t+2 开盘卖出」的**单日持有收益**。
- 若把它理解成「每日都做一次单日持有、收益记在信号日」，则错位是**故意设计**。
- 但问题在于：这个「单日持有收益」被塞进了 `W_lag · r` 的**逐日复利**框架，而 `W_held` 是重叠持有（hold_days 平均），二者时序不匹配——**单日持有的语义和重叠持仓的语义被混用了**。

---

## 4. 关键判断依据（需要进一步确认）

要区分 A/B，需回答一个问题：

> `W_target[t]` 用的信号 `pred_df[t]`，是 **t 日收盘可得**，还是 **t 日收盘后才可得（即 t+1 才可用）**？

- 若 `pred_df[t]` 是 t 日收盘的 OOF 预测，t+1 开盘可执行，则：
  - 正确收益应是 t+1→t+2（记在 t+1，与全仓库 `pct_change` 一致）；
  - 而 `r_wrong[t]` 记在 t 日，配 `W_lag` 后确实**早了 2 天** → 未来函数。
- 若作者把 `r_wrong[t]` 当作「t 日信号在 t+1 开盘买、t+2 开盘卖的持有收益」，则**收益锚定日应该是 t+1 而非 t**，当前把 t 日的信号和 t 日的收益错位配对，仍是 off-by-one。

**初步判断倾向定性 A（存在未来函数）**，但鉴于这会影响全部截面/ML 报告的结论，且作者 docstring 明确声明了「无未来函数」的意图，**需作者本人确认**其 `pred_df` 的时点语义后再定论。

2. 同步修正 `build_portfolio_naive`（仅供对比展示，可保留但标注）；
3. 成本口径统一为买/卖分离（`buy_cost`/`sell_cost`），废弃 `cost/2` 对半；
4. **重跑所有受影响策略报告**，对比新旧夏普，评估结论是否被推翻；
5. 若结论变化，逐份报告更新「方法论修正」章节，记录这次口径统一的修正。
