## 1. 问题陈述

全仓库存在**两套收益定义**并存：

| 模块 | 收益定义 | 记在哪一天 | 成本口径 |
|------|---------|-----------|---------|
| `backtest/engine.py` | `close.pct_change()` | t→t+1 记在 t+1 | 买/卖分离 0.026%/0.076% |
| `backtest/cross_section.py` | `close.pct_change()` | t→t+1 记在 t+1 | 买/卖分离 |
| `models/labels.py` | `close(t+6)/close(t+1)-1` | 持仓期（跨 5 日） | — |
| **`models/portfolio_backtest.py`** | **`close.shift(-2)/close.shift(-1)-1`** | **t+1→t+2 记在 t** | **cost/2 对半** |
| `risk/portfolio.py` | `close.pct_change()`（本次已改） | t→t+1 记在 t+1 | 买/卖分离（本次已改） |

核心分歧在于 `models/portfolio_backtest.py` 的错位收益。

## 2. 错位收益的精确数学含义

已用数值实验验证（2026-09）：

```
r_wrong[t] = close.shift(-2)/close.shift(-1) - 1
           = close(t+2) / close(t+1) - 1      # 记在 t 日
```

即：**t 日的收益字段里装的是 t+1→t+2 的收益**。

配 `W_lag = W_held.shift(1)` 后：

```
port_ret[t] = W_held[t-1] · r_wrong[t]
            = W_held[t-1] · (t+1→t+2 的收益)
```

而 `W_held[t-1]` 由 `W_target.rolling(hold_days).mean()` 得到，`W_target[t-1]` 用的是 **t-1 日的信号**。

因此时序是：**t-1 日的持仓，吃到了 t+1→t+2 日的收益**。

---

## 3. 精确定性（2026-09-05 修正：非未来函数，而是信号延迟错配）

经逐日时序推演 + 受控数值实验，**推翻此前「倾向未来函数」的初步判断**。准确结论如下：

### 3.1 时序配对推演

```
错位收益: r_wrong[t] = close[t+2]/close[t+1]-1   (记在 t 日)
组合收益: port[t] = W_lag[t] · r_wrong[t] = W_held[t-1] · (t+1→t+2 的收益)
而 W_held[t-1] 基于 W_target[t-H .. t-1]，即 t-1 及更早的信号

正确口径: r_std[t] = close[t]/close[t-1]-1       (记在 t 日)
组合收益: port[t] = W_held[t-1] · (t-1→t 的收益)
```

### 3.2 核心结论

- 错位收益让「信号日」到「收益日」之间**隔了 2 天空窗**（t、t+1），而非偷看未来。
- **它不是未来函数**：不拿未来的信号吃过去的收益，方向是「保守的」。
- 实质是**信号延迟错配**：用 t-1（及更早）的信号去吃 t+1→t+2 的收益，等于「信号晚了 2 天才兑现」。

### 3.3 数值验证（受控实验）

| alpha 特性 | 正确口径 SR | 错位口径 SR | 差异 |
|-----------|------------|------------|------|
| 纯随机（rho≈0） | -0.214 | -0.211 | 几乎无影响 |
| 有持续性（rho=0.7，动量风格） | 1.057 | 0.947 | **-10%（低估）** |

**关键发现**：错位收益在有持续性的 alpha（动量/反转等常见风格）下，**会系统性低估真实夏普**（因为信号晚了 2 天，错失了最新 2 天的信息），而非虚高。

### 3.4 对「结论是否被污染」的最终判断

- 错位收益**不会让结论虚高**（不偷看未来），因此现有报告中「夏普虚高」的担忧**不成立**。
- 但它会让**真实 alpha 被低估约 10%**（在动量类风格下），意味着现有报告对「alpha 不成立」的否定性结论，**方向依然可信，甚至偏保守**。
- 作者 docstring 声明「无未来函数」的意图，**在「不偷看未来」这一点上是正确的**，只是「信号延迟错配」导致收益被系统性延迟兑现。

## 5. 建议的收口方案（待批准后实施，影响已量化）

1. 将 `build_portfolio` 的收益定义统一为 `close.pct_change()`（t→t+1 记在 t+1），与全仓库一致；
   **影响**：动量类策略 SR 从低估状态回归真实值（约 +10%），纯随机/弱 alpha 策略几乎不变。
2. 同步修正 `build_portfolio_naive`（仅供对比展示，可保留但标注）；
3. 成本口径统一为买/卖分离（`buy_cost`/`sell_cost`），废弃 `cost/2` 对半；
   **影响**：这是**影响最大**的一项——当前 `COST_BPS=0.003`（双边千三）是铁律标准 0.1% 的 3 倍，收口后成本下降 2/3，所有组合 SR 会**上升**（详见第 7 节量化）。
4. **重跑所有受影响策略报告**，对比新旧夏普，评估结论是否被推翻；
5. 若结论变化，逐份报告更新「方法论修正」章节，记录这次口径统一的修正。

### 7.2 影响方向与量级（真实数据对照，2026-09-05 实测）

用真实 OOF 预测（790 只 × 3886 交易日）做了四象限分解（收益口径 × 成本口径）：

| 口径 | LS 夏普 | LO 夏普 |
|------|--------|--------|
| 错位 + 对半 0.3%（旧） | 0.036 | 1.187 |
| 错位 + 分离 0.1% | 0.926 | 1.530 |
| pct + 对半 0.3% | 0.294 | 1.272 |
| **pct + 分离 0.1%（新）** | **1.175** | **1.613** |

**结论（修正此前「+10%」的低估估计）**：

1. **成本口径是主导因素**：仅把成本从「对半 0.3%」降到「分离 0.1%」，LS 夏普 0.036→0.926（+0.89）。多空组合两端都要换手，0.3% 双边成本对 LS 是致命的。
2. **收益口径独立影响**：固定成本，错位→pct，LS +0.25、LO +0.08。
3. **LO（纯多）受影响温和**：1.187→1.613（+36%），方向一致。
4. **LS（多空）受影响剧烈**：0.036→1.175（+3145%），这是「成本过高 + 收益错位」双重 bug 叠加的结果。

### 7.3 对既有结论的影响（修正）

**此前「核心结论不反转」的判断需要修正**：

1. **LO（纯多）结论不变**：旧 1.187 → 新 1.613，仍是正 alpha，但「日线截面 alpha 弱/不稳定」的定性不变。
2. **LS（多空）结论反转**：旧口径 LS=0.036（几乎无 alpha），新口径 LS=1.175（显著正 alpha）。**旧口径的「多空 alpha 不成立」是被「过高成本 + 收益错位」双重 bug 压出来的错误结论**。
3. 这**不削弱**项目的研究价值，反而印证了项目一贯的方法论：**回测引擎的正确性决定结论的可信度**。旧口径用 0.3% 成本（铁律 3 倍）本身就是一个隐藏 bug，收口后暴露了它把 LS 的真实 alpha 压没了。
4. **必须重跑受影响的 3 份报告**（models/、zz500_pit_trial、zz500_fundamental_trial），尤其是多空结论，更新「方法论修正」章节，记录这次「成本口径 bug + 收益错位」的双重修正。
