## 3. 改动包 A：数据口径（P0，阻断）

### A1 为什么必须换后复权

不只是 VWAP。前复权因子 `f(t)` 由 **t 之后**的除权事件决定，任何"价格绝对水平"类因子在历史上都不可得 —— 这是铁律 3.5 禁止前复权的真正原因。受影响的因子不止 VWAP 那批，还包括 `DELTA(close)`、`ABS(DELTA(close))`、`high-low`、`close**5` 等（见 §8.2）。**可验证的差异**：实测 `vwap/close` 从 1.02 到 4.01 随年份单调放大，这个梯度本身就是"距今年限"的代理变量。

### A2 新增 `data/price_adjust.py`

```python
"""复权因子与真 VWAP 构造。铁律 3.5：截面因子必须后复权。"""
import numpy as np
import pandas as pd
from data.fetcher import load_daily


def adjust_factor(symbol: str, index: pd.DatetimeIndex) -> pd.Series:
    """f(t) = close_adj1 / close_adj3（后复权 / 不复权）"""
    a1 = load_daily(symbol, adjust="1")
    a3 = load_daily(symbol, adjust="3")
    if a1 is None or a3 is None:
        return pd.Series(np.nan, index=index, name=symbol)
    f = (a1["close"] / a3["close"]).reindex(index)
    return f.rename(symbol)


def build_true_vwap(panel: dict, symbols: list[str]) -> pd.DataFrame:
    """把 amount/volume（原始均价）拉到与后复权 close 同口径。

    vwap_adj1 = (amount / volume) * f(t)，  f(t) = close_adj1 / close_adj3
    """
    vwap_raw = panel["amount"] / panel["volume"]
    F = pd.DataFrame({s: adjust_factor(s, vwap_raw.index) for s in symbols}).sort_index()
    return vwap_raw * F.reindex(columns=vwap_raw.columns)


def validate_raw_vwap(symbol: str, floor: float = 0.97, ceil: float = 1.03) -> tuple[bool, float]:
    """gate: (amount/volume) / close_adj3 中位数应 ≈ 1.0"""
    a3 = load_daily(symbol, adjust="3")
    if a3 is None:
        return False, np.nan
    r = ((a3["amount"] / a3["volume"]) / a3["close"]).replace([np.inf, -np.inf], np.nan)
    med = float(r.median())
    return (floor <= med <= ceil), med
```

## 10. 顺序上的三个判断

**① 先把 gate 跑通，再改代码。** 如果 VWAP 还原失败（A3 不过），整个 A 包降级成 TP 代理，B3 语义表里 40 行的"依据"栏要重写。先花 10 分钟验证，比写完再返工便宜。

**② 不要先改报告。** 报告是产出的投影，口径定型前重写等于白写两遍。

**③ golden 基线必须最后重建。** 它锁的是"修复完成后的正确状态"。早上重建会锁住半修复状态，等于把 bug 固化成"预期行为"。

## 11. 风险与不可逆点

| 风险 | 影响 | 缓解 |
|---|---|---|
| baostock 下载量（1580~3000 次请求）触发限流 | A 包中断 | 分批 + 失败重试，缓存幂等 |

| 因子池换血导致 models 结论反转 | 已发布的 CSI300/zz500 结论全部作废 | 这正是必须现在做的原因——带病结论比没有结论更危险 |
| `close_matrix` 变后复权，某下游脚本按绝对价格筛选 | 交易决策变化 | 全库 grep `close.*[<>]` 复核；目前只有 `risk/portfolio.py` 的涨跌停判断，属相对判断，安全 |
| 报告覆盖后原数字丢失 | 无法对比修复前后差异 | 先 `git tag`，报告顶部留作废横幅 |

**唯一真正不可逆的操作是「用新数字直接覆盖旧报告」**。其余改动都可以通过 git 回滚。
