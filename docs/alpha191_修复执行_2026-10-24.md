### 4. 额外优化：TSRANK 向量化（2026-10-24 追加）

全量重筛启动后发现 `_tsrank_1d` 用 `rolling.apply` 逐窗口回调，783 列 × 3886 行下单因子需 30–60 秒，全库重筛 1–2 小时。

改为 `sliding_window_view` + 广播比较：

```python
win = np.lib.stride_tricks.sliding_window_view(arr, n)
valid = ~np.isnan(win).any(axis=1)
pct[valid] = (win[valid] <= win[valid][:, -1:]).sum(axis=1) / n
```

- 语义等价：`searchsorted(sort(x), x[-1], side='right')/n` ≡ `(x <= x[-1]).sum()/n`
- 数值验证：n=5/6/10 下最大绝对差 **0.00e+00**，含 NaN 窗口位置完全一致
- 单列加速 8x；golden 基线 `--verify` 仍全部一致

## 七、Selection Bias 消除（CSI300 补齐，2026-10-24 追加）

新增脚本：`models/walk_forward_pit_select.py`
每年只用截至 Y-1 年末的数据重算 IC_IR / FM_t / CS_eff → 三维过滤 → 冗余剔除 → 选出该年度池 → 重训 → 预测 Y 年。

两阶段实现（内存约束）：Stage A 分批算 179 因子（已排除 12 个退化因子）的逐日 IC / FM λ 序列（约 25 分钟，结果缓存 `wf_pit_ic_panel.csv` / `wf_pit_fm_panel.csv`）；Stage B 逐年选池 + 只算"历年池并集"（132 个）的因子矩阵再训练。

### 结果

| 口径 | 年化 | 夏普 | MDD |
|---|---|---|---|
| 修复前 · 固定池（含 selection bias） | 5.96% | 0.434 | −31.4% |
| 修复后 · 固定池（含 selection bias） | 20.07% | **1.427** | −29.0% |
| **修复后 · PIT-Select（消除 bias）** | **4.84%** | **0.510** | −22.6% |

**selection bias = −64%**（1.427 → 0.510），与 zz500 侧的 −79% 同量级。

**所以第六节里的 1.427 不可引用**。真实可引用的样本外数字是 **年化 4.84%、夏普 0.510**。

### 逐年（PIT-Select）

| 年 | 夏普 | 年 | 夏普 |
|---|---|---|---|
| 2015 | +0.578 | 2021 | +0.495 |
| 2016 | +1.888 | 2022 | +0.225 |
| 2017 | +0.436 | 2023 | **−0.110** |
| 2018 | +1.661 | 2024 | +1.501 |
| 2019 | +0.319 | 2025 | **−0.830** |
| 2020 | +0.706 | | |

分布与 zz500 不同：zz500 的超额几乎全部集中在 2015–2016 小盘泡沫，CSI300 这里是
2016/2018/2024 强、2023/2025 弱，没有单一年份主导。

### 年度池的重合度

11 年选出的池高度稳定：`alpha044, 169, 142, 001, 045, 108, 116, 003` 几乎每年都在。
池换手低于预期，说明 selection bias 主要来自「用全样本 IC_IR 排序挑 top15」这一步，
而不是来自池子本身的年际漂移。

### 一个仍然无法回答的问题

修复前的固定池 WF（0.434）同样含 selection bias。若假设两侧 bias 幅度相近（−60%~−79%），
修复前的去 bias 值约在 0.09–0.17。这样看修复后的 0.510 是实质性改善。
但这是**推测**——修复前没有跑过 PIT-Select（当时脚本不存在），不能当结论。
可引用的事实只有两条：① 修复后去 bias = 0.510；② 同口径下固定池 1.427 含 −64% 的偏差。

- B→C 池换血：WF +11%（1.285 → 1.427）
- C→C′ 去 selection bias：−64%（1.427 → 0.510）

**改善的 86% 来自口径修复，池换血贡献很小。** 这修正了第六节 §6.5 第 1 条保留意见的
不确定性——现在可以确定主因是口径，不是换池。

### 仍未分离的残留

A 组用的是 1,025,288 行的 X_matrix（旧 pipeline 产物），B/C 是 1,148,569 行。
样本集差异（783 只 vs 旧 pipeline 的 790 只口径、日期覆盖）仍混在 A→B 的差异里。
旧口径代码已被覆盖，无法精确重建 A 组，故标注为「残留不确定性」而非消除。

### 为什么去掉前视反而变好（定性解释）

前复权带来的不是 alpha 而是**噪声**：复权因子各股票不同，`vwap-close`、`DELTA(close)`
这类价格水平量因此混入「该股累计分红送股幅度」这一与未来收益无关的分量，
在截面排名里稀释真实信号。未来分红与未来 5 日收益无关——前视不等于有信息，只是污染。

这只是解释，没有定量证据支撑（IC 降、回测升的方向不一致仍未解）。

## 九、算子层双实现互证（2026-10-24 追加）

### 为什么不是外部数据源对拍

原计划抽 20 个因子对独立数据源（聚宽/米筐/BRAIN）。实际不可行：沙箱网络只放行代理白名单，
`akshare.stock_zh_a_hist` 直接抛 `ProxyError`（`push2his.eastmoney.com` 无法连接），
禁用代理后直连也被断。

替代方案：**内部双实现互证**——用纯 numpy 另写一套 16 个算子 + 5 个因子，
与 `signals/alpha191/operators.py` 的 pandas 实现对比。
脚本：`tests/verify_operators_independent.py`，明细：`tests/operator_dual_impl_report.csv`。

局限必须写明：**它无法发现「两套实现犯了同一个公式理解错误」**。
能覆盖的是实现风险——窗口边界、NaN 传导、并列处理、自由度、浮点路径。

### 抓到的两个真 bug

**① REGBETA 的 ddof 不一致（严重）**

```python
cov = y.rolling(n).cov(x)        # pandas 默认 ddof=1
var = x.rolling(n).var(ddof=0)   # 总体方差
return cov / var
```

分子分母自由度不同 → β 系统性放大 (n−1)/n 倍。n=5 时 **+25%**（实测相对误差 0.200）。
影响 alpha142/143/144/145/146/147/148/149 八个因子，其中 **142 在最终池**。

修复：`cov = y.rolling(n).cov(x, ddof=0)`。

**② SMA 的初值路径与研报不等价（中等）**

原实现用 `ewm(alpha=m/n, adjust=False)` 的值填充 t≥n，只在 t=n−1 处覆盖为前 n 日均值。
但 ewm 的递归是从 x[0] 起步的——等于在 n−1 打个补丁，之后仍走 ewm 自己的历史路径。
研报语义是「均值初值 → 纯递归」，两者不等价（实测偏差 **0.13%~0.46%**）。

影响 alpha009、076–093（其中 **087 在最终池且是 IC_IR 最高的因子**）、173、174。

修复：改为显式递归，初值取前 n 日均值，NaN 处沿用上一值（与 `ignore_na=True` 语义一致）。

### 修复后

```
✅ 全部 85 项逐位一致（NaN 位置 + 有限值，相对误差 < 1e-9）
  16 个算子 × 5 只股票 = 80 项，5 个因子 × 5 只 = 25 项（含重复计数）
```

`factor_001/003/011/018/055` 两套独立实现全部一致——说明公式转写与算子组合正确。

### 连带影响

这两个修复改变了 087/142 等池内因子，因此：
- golden 基线已重建（187/191 有效），`--verify` 通过
- `pytest tests/test_alpha191_health.py` 4 项通过
- **purify → select_features → models 全链需要再跑一次**（本轮已重跑）
